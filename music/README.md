# Music

Put music files (MP3, OGG or M4A) in this folder and list them in `tracks.json`:

```json
["march-of-liberty.mp3", { "file": "evening-broadcast.ogg", "title": "Evening Broadcast" }]
```

Tracks play shuffled, with a pause of 20 to 60 seconds between them. The MUSIC slider in the menu sets the volume.
Only add music you have the rights to share: the game is public on GitHub Pages.
